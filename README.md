# AyuGram Desktop

This repository contains **universal pre-built AyuGram Desktop binaries** for Linux, distributed for Debian as .deb packages.

## How to install

1. If you're using Debian, download latest package [from Releases](https://github.com/reddxae/ayugram-desktop-deb/releases/latest) and install it:
```bash
sudo apt install <path_to_package>
```
2. If you're on different distro, and the only option you have is to use binary:  

```bash
# Make binary executable
sudo chmod +x AyuGram

# Copy binary to the standard location, such as /usr/bin
sudo cp AyuGram /usr/bin
```

## Info
All builds are produced following [the official guide](https://github.com/AyuGram/AyuGramDesktop/blob/dev/docs/building-linux.md). Thanks to the AyuGram developers at Radolyn Labs and the community for an excellent client!
